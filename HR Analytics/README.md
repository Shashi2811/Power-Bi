# HR Analytics Dashboard 📊

## Project Overview
This project analyzes employee attrition and workforce demographics using **Power BI**.  
The aim is to uncover key HR insights such as attrition trends, department-wise turnover, and employee satisfaction levels.

---

## Key Insights
- **Total Employees**: 1470  
- **Total Attrition**: 237 (16%)  
- **Active Employees**: 1233  
- **Average Age**: 37  

### Attrition Breakdown
- **By Department**:  
  - Sales: 38.55%  
  - HR: 35.59%  
  - R&D: 25.86%  

- **By Gender**:

  - Female: 46.52%  

- **By Education Field**:

- **By Age Group**:  
  - 25-34 years: 554 employees  
  - 35-44 years: 505 employees  
  - 45-54 years: 245 employees  
  - Under 25: 97 employees  
  - Over 55: 69 employees  

---

## Dashboard Features
- **Interactive filters** for gender, age group, and department  
- **Attrition KPIs**: total attrition, attrition rate, active employees, average age  
- **Visualizations**: bar charts, pie charts, donut charts, and stacked bars for satisfaction levels  
- **Job Role Analysis**: satisfaction vs dissatisfaction trends across roles
